01 / BACKEND SYSTEM

PatientFlow Cloud

A Spring Boot microservices project spanning patient records, billing, analytics, and authentication.

IMPLEMENTATION

ENGINEERING CHOICE

The repository separates services and includes Docker and AWS infrastructure configuration. Synchronous calls and asynchronous events serve different workflow needs.

SOURCE & SCOPE

The repository contains separate service modules, integration tests, and Docker and AWS infrastructure configuration. These notes cover the implemented architecture and repository structure.

02 / REDIS & BACKEND APPLICATION

Life Preference

A Spring Boot merchant-review learning project based on the Heima Dianping course, exploring Redis through login, caching, and coupon flash sales.

LOGIN & CACHING

Redis stores shared sessions, with interceptors checking login state. Merchant queries use Cache Aside caching with update and expiration handling.

ASYNCHRONOUS ORDERS

Requests execute Lua purchase validation. A background Redis Streams consumer creates orders using a Redisson user lock, a duplicate-order check, and a MySQL transaction. The consumer includes ACK and pending-list handling.

SOURCE & PRACTICE

The flash-sale script, order service, and database schema document the course-based implementation. The worker uses a single-thread executor and a fixed consumer identity; multi-worker scaling would require further design and testing.

03 / VERSION CONTROL

Gitlet

A CS61B-based Java learning project exploring object persistence, commit graphs, and branch state through version control.

SNAPSHOTS & STORAGE

Blobs hold file contents; commits map file names to blob IDs and store parent references. Serialized objects are persisted under SHA-1 IDs, with separate addition and removal staging areas.

GRAPHS & STATE

Branch references locate commits. Graph traversal collects common ancestors; snapshot comparisons identify changes and produce conflict markers. Push, fetch, and pull work with another local repository directory, not Git network protocols.

VERIFICATION & SCOPE

Local design notes and source were reviewed, then compiled in an isolated directory to check basic commit and branch flows. Known follow-up work includes branch-reference updates during merging and fast-forward behavior.

Agent Skills Manager

Create, manage, and publicly share Markdown-based agent skills.

IMPLEMENTATION

ENGINEERING CHOICE

The repository documents bcrypt password hashing, httpOnly-cookie authentication, and ISR for the public skills gallery.

SOURCE & SCOPE

The app routes, Prisma schema, and README show how skills move from authenticated editing to the public gallery. These notes cover the application flow and documented authentication design.

05 / BROWSER PRODUCT

Inkline

Open a PDF, draw and place a signature, then export the document in the browser.

IMPLEMENTATION

PDF.js renders pages to canvas; pdf-lib embeds signatures in PDF page coordinates. Placement survives viewport resizing.

ENGINEERING CHOICE

Files stay in the browser tab. The production Content Security Policy uses connect-src 'none' to block script-initiated network requests.

SOURCE & SCOPE

The live app demonstrates the import-to-export flow and the architecture notes explain it. Rotated and encrypted PDFs are outside the supported scope.
