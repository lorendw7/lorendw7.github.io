01 / RA RESEARCHEARLY PROTOTYPE
MODEL A→CONTEXT→MODEL B

Kyudai LLM Context Bridge

My RA research project on context continuity when switching language models. The selected design combines a Go bridge, Ollama inference, and a Python Mem0 OSS worker, with source-linked memory and separate user and laboratory scopes.

Built Localhost Go health endpoint and test; architecture and evaluation plan documentedNext Model switching, memory, persistence, authentication, and Genkai evaluation

Project-site demo uses synthetic data. Token savings and model quality have not been measured. This is an independent project originating in RA work, not an official university service.

PROCMON / PROCESS SAMPLING/proc snapshot PID · state · user · RSS↓CPU deltasMemory sort↓Terminal view live refresh · one-shot mode

Procmon

A small top-like process monitor written in C. It reads Linux /proc, samples per-process CPU time, reports resident memory, and refreshes a sortable terminal view.

Engineering focus: procfs parsing, delta-based CPU calculation, POSIX process metadata, signal-safe shutdown, and a dependency-free Make build.

CLinux / procfsPOSIX
